## Brand & Style

This design system embodies a high-velocity, bilingual cyber-academic command center tailored for academic test preparation and vocabulary mastery. It merges the focused, low-fatigue immersion of an esports telemetry terminal with the structured clarity of an enterprise learning dashboard.

The emotional signature is empowering, rigorous, and gamified:
- **Atmosphere:** Deep nocturnal canvases eliminate eye strain during late-night study sessions, energized by razor-sharp neon emerald hits, warm flame ambers, and tactical cyans.
- **Duality:** Combines nocturnal focus for deep-dive testing and 3D flashcards with high-contrast daylight card surfaces when parsing dense analytical reports or lengthy reading passages.
- **Personality:** Precision-driven, disciplined, modern, and motivating. It elevates academic preparation from passive reading into an active, progression-oriented campaign.

## Colors

The palette is engineered around high-contrast visual cues on deep nocturnal foundations, with daylight adaptations for specific analytical contexts:

### Core Foundation
- **Canvas Shell (`#0c0f17` / `#0a0d14`):** Base workspace canvas providing total visual immersion.
- **Container Surfaces (`#141824` / `#111723`):** Slate-black cards, panels, and examination arenas.
- **Surface Elevated (`#1a2030` / `#181e2e`):** Active row highlights, popovers, and elevated controls.
- **Structural Outlines (`#1f2738` / `#1e293b`):** Crisp hairline borders providing boundary clarity without visual clatter.

### Interactive & Accent Channels
- **Primary Emerald (`#00c569` / `#10b981`):** Dominant success signal, verified comprehension, active route indicators, and mastery milestones.
- **Action Cobalt (`#2563eb`):** Primary transactional drivers, command anchors, and daytime interface focal points.
- **Milestone Amber (`#f59e0b` / `#fbbf24`):** Gamified streak fires, Spaced Repetition hints, and active attention alerts.
- **Telemetry Cyan (`#06b6d4` / `#22d3ee`):** Source curriculum tags, syllabus units, and reading mode navigation.

### Daylight Alternative
- **Daylight Canvas (`#f7f9fc`):** Crisp daylight environment for daylight exam settings.
- **Daylight Surface (`#ffffff`):** Pure white container surfaces bounded by slate hairlines (`#e5e7eb`).

### Gamification & State System
- **Error / Mistake (`#ef4444` / `#f43f5e`):** Mistake feedback, weak word tags, and error alerts.
- **League Tiers:** Bronze (`#cd7f32`), Silver (`#cbd5e1`), Gold (`#fbbf24`), Platinum (`#22d3ee`), Diamond (`#a855f7`), Champion (`#f43f5e`).

## Typography

The typographical engine leverages neutral, high-density neo-grotesque type across Latin characters and numerals, paired seamlessly with companion Indic glyph engines (such as Hind Siliguri or Noto Sans Bengali) in localized contexts.

### Architectural Rules
- **Display Weights & Negative Tracking:** Display and large headline roles use tight tracking (`-0.01em` to `-0.025em`) and high weights (`700` through `900`) to assert visual authority during active flashcard sessions and exam screens.
- **Vertical Clearance:** Body copy maintains a generous line height ratio (`1.6` to `1.65`) to allow complex multiline bilingual phrasing and phonetic annotations without collision.
- **Tabular Rigor:** Digital timers, exam score tallying, question indices (`Q01` - `Q46`), and XP matrices enforce tabular figure features (`tnum`) to eliminate layout displacement during live updates.

## Layout & Spacing

The layout is built on a responsive 12-column grid capped at a maximum shell width of `1550px`. It uses an asymmetric structure tailored for concurrent dashboard tasks:

### Grid Distribution
- **Desktop (>= 1024px):** 8 columns dedicated to primary learning workflows (Active Flashcard Stage, Examination Engine, Question Passages) coupled with a persistent 4-column telemetry sidebar (Streak Monitors, League Standings, Weak Area Repetition Queue).
- **Tablet (640px - 1023px):** Collapses into a balanced 2-column stacked grid with sidebar metrics flowing directly beneath active modules.
- **Mobile (< 640px):** Single-column stacked stream prioritizing the urgent action (Daily Goal Progress -> Active Exam Session -> Weak Words).

### Spacing Cadence
- All spacing conforms to a baseline 4px module.
- Gutters scale from `1rem` on handheld viewports to `1.5rem` (`24px`) on desktop viewports.
- Inner card padding follows a multi-tier step: compact elements use `0.875rem` (`14px`), standard modules use `1.25rem` (`20px`), and hero focal stages feature `1.75rem` (`28px`).

## Elevation & Depth

This design system avoids muddy, multi-layer drop shadows, opting instead for structural depth created via surface luminance tiers, hairline framing borders, and glowing ambient backdrops:

### Surface Tiers
- **Layer 0 (Canvas Base):** Deep void (`#0c0f17`) anchoring the viewport.
- **Layer 1 (Standard Card):** `#111723` with a crisp `1px` stroke of `#1f2738` providing structural separation.
- **Layer 2 (Floating Modals & Flyouts):** `#181e2e` with `backdrop-filter: blur(16px)` and `#2c3d5c` hairline borders.

### Dynamic Accent Haloes
Interactive and gamified milestones project luminous, low-spread color blooms:
- **Success & Mastery State:** Answer option cards project `0 0 25px rgba(16, 185, 129, 0.35)` with an emerald border ring.
- **Error Shake State:** Incorrect selections pulse with `0 0 25px rgba(239, 68, 68, 0.35)` alongside a rapid horizontal oscillation.
- **Active Hot Streak:** Streak containers cast an ambient underglow `0 12px 32px rgba(245, 158, 11, 0.15)`.

## Shapes

The geometric identity balances clean utility with welcoming, touch-friendly softness:
- **Base Components:** Inputs, action buttons, filter pills, and navigation links feature `0.5rem` (`8px`) to `0.75rem` (`12px`) corner rounding.
- **Container Cards:** Standard cards utilize `1rem` (`16px`) to `1.25rem` (`20px`) curvature, framing dense content cleanly.
- **Interactive Stages:** 3D Flashcards and Hero Welcome units employ `1.5rem` (`24px`) radii, reinforcing their tactile, card-like feel.
- **Tags & Status Badges:** Badges, question index dots, and status indicators are fully rounded pills (`9999px`).

## Components

### Buttons
- **Primary Cobalt CTA:** Built for core transactional milestones. Background `#2563eb`, hover `#1d4ed8`, text white, minimum height `46px`, corner radius `12px`. Subtle scale feedback (`active:scale-95`) on touch.
- **Emerald Accent Action:** Used for session progression ("Resume Practice", "Submit Exam"). Styled with an emerald gradient (`#00c569` to `#0d9488`), dark shadow lift, and high-contrast white typography.
- **Ghost Dark Controls:** Background `#111723`, border `1px solid #1e293b`, hover background `#161e2e`. Used for audio pronunciation triggers, mode toggles, and secondary navigation.

### Option Buttons (MCQ Exam Engine)
- **Neutral State:** Slate surface (`#111723`), border `#1e293b`, text `#e2e8f0`. Left-aligned option lettering in muted mono chips.
- **Correct State:** Intense emerald flood (`rgba(6, 78, 59, 0.9)`), border `#10b981`, ring glow `0 0 25px rgba(16, 185, 129, 0.35)`, bold text `#ecfdf5`.
- **Incorrect State:** Rose flood (`rgba(136, 19, 55, 0.9)`), border `#f43f5e`, ring glow `0 0 25px rgba(244, 63, 94, 0.35)`, text `#fff1f2`.
- **Disabled State:** Opacity `0.4`, surface `#090d15`, border `#182030`.

### Cards & 3D Stages
- **Standard Dashboard Cards:** Backdrop `#111723`, border `1px solid #1e293b`, radius `16px`. Subtle hover translation (`-2px`) with border color brightening to `#334155`.
- **3D Vocabulary Flashcards:** Container utilizes CSS 3D perspective (`perspective: 1200px`) with dual front/back faces featuring `backface-visibility: hidden`. Gradient surface `#111723` via `#0e1420` to `#0c0f17`. Features isolated audio trigger wells with active soundwave pulses.

### Inputs & Selectors
- **Search & Text Input:** Surface `#0c0f17`, border `#1e293b`, radius `12px`, padding `10px 16px`. Focus transitions cleanly to border `#00c569` with a subtle focus ring `0 0 0 3px rgba(0, 197, 105, 0.2)`. Placeholder text in muted slate (`#64748b`).
- **Filter Chips:** Capsule shape, background `#111723`, border `#1e293b`, text `#94a3b8`. Selected chip switches to `#00c569/15` fill, `#00c569/50` border, and bright emerald text.

### Domain-Specific Components
- **Question Matrix Breadcrumb Rail:** Horizontal scroll container showing discrete question status bubbles: Current (illuminated emerald ring), Complete (solid emerald dot), Flagged Mistake (crimson dot), In Review (cyan dot), and Unanswered (slate ring).
- **Streak & Freeze Shield:** Compact widget showing consecutive study days with an animated flame graphic in amber gold, coupled with an active freeze-protection shield icon indicating exam buffer status.
- **Weak Word Spaced Repetition (SRS) Chips:** Specialized danger tags indicating revision necessity, complete with mistake frequency counters and direct "Review Now" shortcut triggers.
